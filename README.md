# Share Calculator Web App

This is a simple web page that helps you decide how many shares to buy when trading. It shows you how many shares you can buy and how much money you will use, while only risking a small part of your money.

## How to Use

1. **Open the Web Page:**  
   Open the `index.html` file in your web browser (like Chrome, Firefox, or Safari).

2. **Enter Your Information:**  
   - **Total Money:** Type in how much money you have.
   - **Buy Price:** Type in the price at which you want to buy the share.
   - **Stop Loss Price:** Type in the price where you want to stop losing money.
   
3. **Choose Your Risk Type:**  
   - You can choose to risk a **percentage** of your money (like 1%).
   - Or you can choose to risk a **fixed amount** (like $100).

4. **Calculate:**  
   Click the "Calculate" button.  
   The page will show you:
   - How many shares to buy.
   - How much money will be used to buy the shares.

## What You Need

- A computer.
- A web browser (Chrome, Firefox, Safari, etc.).

Enjoy using the Share Calculator!
